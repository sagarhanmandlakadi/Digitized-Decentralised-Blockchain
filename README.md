# Digitized & Decentralized Blockchain Technology

An immutable, secure user-admin issue tracking network powered by SHA-256 cryptographic chaining.

## 🛠️ System Requirements
* Python 3.10+
* Streamlit 1.32.0+
* Pandas

## 🏗️ Core Architecture
1. **Cryptographic Engine (`blockchain.py`)**: Implements sequential block mapping using SHA-256 digital signatures to bind transactions securely via parent hash continuity (`previous_hash`).
2. **Web Portal Application (`app.py`)**: Provides user account registration, authenticated logging terminals, public verification track tools, and a passkey-secured administration command console.
